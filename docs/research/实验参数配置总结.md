## 一、论文实验配置标准

### 1.1 Xu et al. 2022 - POI-aware RDW（单用户）

#### 物理空间配置
| 参数 | 值 | 说明 |
|------|----|----|
| 仿真空间尺寸 | 5m×5m, 10m×10m | 三种环境布局各两种尺寸 |
| 用户实验空间 | 5m×5m | 受HMD线缆长度限制 |
| Buffer区域宽度 | 0.55m | 障碍物和边界周围的安全区 |
| 离散化网格边长 | 0.5m | 基于人体肩宽(34-38cm)和步长(50-70cm) |
| 离散方向数 | 30个 | 均匀划分360° |

#### RDW核心参数
| 参数 | 值 | 说明 |
|------|----|----|
| 曲率增益阈值半径 | R = 7.5m | 广泛接受的RDW标准值 |
| 虚拟目标到达距离 | 0.05m | 小于此距离视为到达目标 |
| 用户移动速度 | 1.0 m/s | 仿真用户恒速 |
| 用户旋转速率 | π/2 rad/s | 约90°/秒 |

#### 实验设计
| 项目 | 配置 | 
|------|------|
| 实验类型 | 仿真实验 + 用户实验 |
| 用户数量 | 单用户 |
| 虚拟路径 | 100条随机生成 |
| 每条路径目标点数 | 100个 |
| 目标生成距离 | 2-6m |
| 目标生成角度 | -π到π |
| 重复次数 | 仿真100次，用户实验26人 |
| 用户实验虚拟行走距离 | 50m/次 |

#### 评价指标
- **主要指标**：Reset数量、Reset-Target距离
- **辅助指标**：预处理时间、主观反馈

#### 对比方法
S2C, S2O, ZigZag, SRL, DAPF, MAPF, REA, TAPF（共8种）

### 1.2 Dong et al. 2021 - Dynamic Density-based RDW（多用户）

#### 物理空间配置
| 参数 | 值 | 说明 |
|------|----|----|
| 仿真空间尺寸 | 20m×20m, 30m×30m, 40m×40m | 大规模多用户场景 |
| 用户实验空间 | 30m×30m | 体育馆实验 |
| 碰撞判定距离 | 1.0m | 距离用户或边界<1m视为碰撞 |

#### RDW核心参数
| 参数 | 值 | 说明 |
|------|----|----|
| 旋转增益（压缩） | 0.8 | 对应1.25倍虚拟旋转 |
| 旋转增益（膨胀） | 1.49 | 对应0.67倍虚拟旋转 |
| 最大旋转角度 | 30°/sec | 旋转增益应用上限 |
| 最大曲率角度 | 15°/sec | 曲率增益应用上限 |
| 曲率增益半径 | 7.5m | 与Xu论文一致 |

#### 算法特定参数（DDB-RDW）
| 参数 | 符号 | 值 | 说明 |
|------|------|----|----|
| 平衡系数 | α₁, α₂, α₃ | 1, 1.3, 1 | 密度力、引力、APF力的权重 |
| 转换系数 | β | 500 | 密度差转密度力的系数 |
| 标准密度系数 | σ | 0.55 | 标准密度函数的调节参数 |
| 引力系数 | ε | 2 | 引力计算的指数 |
| 切圆半径 | r | 8步 | 双密度最优点选择参数 |

#### 实验设计
| 项目 | 配置 |
|------|------|
| 实验类型 | 仿真实验 + 应用验证 |
| 用户数量 | 4-9人 |
| 空间尺寸组合 | 3种（20×20, 30×30, 40×40 m²） |
| 实验组合总数 | 18组（6个用户数×3个空间尺寸） |
| 虚拟路径长度 | 200m |
| 导航点间距 | 4-8m |
| 转向角度 | 90°（方向随机） |
| 用户移动速度 | 1.0 m/s |
| 重复次数 | 每组100次，共1800次实验 |

#### 评价指标
- **主要指标**：总Reset数量、边界Reset数量、用户间Reset数量、与中心的平均物理距离
- **辅助指标**：占领区域面积（占点游戏）、空间利用率

#### 对比方法
主要对比Dynamic APF-RDW

## 三、实验部分需要陈述的关键信息

### 3.1 必须明确的参数（按优先级）

#### ⭐ 核心RDW参数（最重要）
1. **曲率增益半径**：7.5m（与论文标准一致）
2. **旋转增益范围**：压缩 -0.2 ~ 膨胀 0.49
3. **平移增益范围**：压缩 -0.14 ~ 膨胀 0.26
4. **用户移动速度**：1.0 m/s
5. **旋转速度**：90°/s (π/2 rad/s)

#### ⭐ 物理空间配置
1. **空间尺寸**：需要在实验中明确指定（如10m×10m）
2. **用户数量**：需要明确（你的项目是多用户）
3. **Buffer宽度**：0.5m（reset触发缓冲区）
4. **碰撞判定距离**：需要明确定义

#### ⭐ 实验设计参数
1. **虚拟路径长度**：建议200m（参考Dong论文）
2. **目标点生成规则**：距离范围、角度范围
3. **重复次数**：建议至少100次
4. **到达目标阈值**：0.05m

#### ⭐ 评价指标定义
根据你的研究目标，需要明确定义：
- **I_short_event_τ**：τ取值（1m, 2m, 3m）
- **D_next_min**：事件后最短连续行走距离
- **N_interrupted**：被打断用户数
- **I_bilateral**：双边reset指示
- **Total reset rows**：总reset数量

### 3.2 算法特定参数

#### 主动重置触发参数（需要补充）
根据你的文档，需要明确：
```
T_lead = 0.30s         // 提前时间
θ_max = 0.50m          // 最大恢复余量阈值
θ_min = 0.15m          // 最小恢复余量阈值
δ = 0.20m              // 最小收益门槛
v_min = 0.05 m/s       // 最小接近速度
w = 5 frames           // 帧窗口
k = 3 frames           // 判定阈值
```

### 3.3 统计分析方法

参考论文使用的方法：
1. **正态性检验**：Shapiro-Wilk test
2. **方差齐性检验**：Levene's test
3. **参数检验**：
   - Welch's ANOVA（方差不齐时）
   - One-way ANOVA（方差齐性时）
4. **非参数检验**：
   - Kruskal-Wallis H test
   - Mann-Whitney U test
5. **事后检验**：
   - Games-Howell test
   - Tukey's HSD test
   - Bonferroni校正
6. **显著性水平**：α = 0.05

```yaml

  尺寸: 10m × 10m

  曲率半径: 7.5m
  旋转增益: [-0.2, 0.49]
  平移增益: [-0.14, 0.26]
  
主动重置参数:
  T_lead: 0.30s

  θ_min: 0.15m
  δ: 0.20m

  - I_short_event_τ (τ=1m, 2m, 3m)
```
